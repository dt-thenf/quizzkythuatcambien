# Ảnh gốc câu hỏi

Các ảnh PNG gốc đã được đóng gói riêng thành `anh-goc-ngan-hang-cau-hoi.zip` đính kèm trong cuộc trò chuyện. Giải nén vào repository (gốc repo) để bổ sung `cau hoi/screenshots/*.png`. Không thay đổi tên ảnh: các mục `screenshot` trong `../questions.json` tham chiếu trực tiếp tên gốc. Các SVG ở `../figures/` là hình dựng lại cho giao diện web, không thay thế ảnh gốc.
